Last modified: 2026-02-19

Native v3 `parseShow()` dispatch includes:

- `SHOW ALL`
- `SHOW TRANSACTION ISOLATION LEVEL`
- `SHOW TABLES`
- `SHOW DATABASES`
- `SHOW COLUMNS FROM`
- `SHOW INDEXES`
- `SHOW INDEX [HEALTH|USAGE|STORAGE|CONTENTION|OPTIONS]`
- `SHOW CREATE TABLE`
- `SHOW TABLE`
- `SHOW TRIGGER[S]`
- `SHOW VIEW[S]`
- `SHOW PROCEDURE[S]`
- `SHOW FUNCTION[S]`
- `SHOW DOMAIN[S]`
- `SHOW GENERATOR[S]` and `SHOW SEQUENCE[S]`
- `SHOW SCHEMA[S]`
- `SHOW ROLE[S]`
- `SHOW GRANTS`
- `SHOW JOBS`, `SHOW JOB`, `SHOW JOB RUNS`
- `SHOW CHECK[S]`
- `SHOW COLLATION[S]`
- `SHOW COMMENT[S]`
- `SHOW DEPENDENCIES`
- `SHOW PACKAGE[S]`
- `SHOW SQL DIALECT`
- `SHOW TIME ZONE`
- `SHOW VERSION`
- `SHOW DATABASE`
- `SHOW SYSTEM`
- `SHOW METRICS`
- `SHOW PARSER VERSION`
- Generic variable form: `SHOW <name>[.<name>...]`

Additional top-level show/control command groups:
- `SHOW CLUSTER STATE`, `SHOW CLUSTER ROUTING PLAN`, `SHOW CLUSTER ADMISSION STATUS`
- `SHOW CUBE STATS`, `CUBE SHOW STATS`

Object-level coverage details are in [DDL](../ddl/README.md).
