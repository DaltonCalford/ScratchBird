Closed families in 0.1.0:
- logical: `AND`, `OR`, `NOT`, `IS NULL`, `IS NOT NULL`
- bitwise: `&`, `|`, `^`, `~`
- shift: `<<`, `>>`

Known limits:
- wide numeric operands remain partial for some bitwise/div/mod combinations
