# Numeric Types

Integer and floating-point number types.

## Integer Types

| Type | Storage | Min | Max |
|------|---------|-----|-----|
| `SMALLINT` / `INT2` | 2 bytes | -32,768 | 32,767 |
| `INTEGER` / `INT` / `INT4` | 4 bytes | -2,147,483,648 | 2,147,483,647 |
| `BIGINT` / `INT8` | 8 bytes | -9.2×10¹⁸ | 9.2×10¹⁸ |

### Usage

```sql
CREATE TABLE counts (
    small_val SMALLINT,
    normal_val INTEGER,
    large_val BIGINT
);

INSERT INTO counts VALUES (100, 1000000, 9999999999999);
```

## Serial Types (Auto-Increment)

| Type | Underlying | Range |
|------|------------|-------|
| `SMALLSERIAL` / `SERIAL2` | SMALLINT | 1 to 32,767 |
| `SERIAL` / `SERIAL4` | INTEGER | 1 to 2,147,483,647 |
| `BIGSERIAL` / `SERIAL8` | BIGINT | 1 to 9.2×10¹⁸ |

### Usage

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100)
);

-- SERIAL is equivalent to:
CREATE SEQUENCE users_id_seq;
CREATE TABLE users (
    id INTEGER NOT NULL DEFAULT nextval('users_id_seq'),
    name VARCHAR(100)
);
```

### GENERATED (SQL Standard)

```sql
CREATE TABLE products (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name VARCHAR(100)
);

-- With start and increment
CREATE TABLE orders (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY (START WITH 1000 INCREMENT BY 1),
    total DECIMAL(10,2)
);
```

## Decimal/Numeric Types

Exact precision for financial calculations:

| Type | Description |
|------|-------------|
| `NUMERIC(p, s)` | Precision p, scale s |
| `DECIMAL(p, s)` | Same as NUMERIC |
| `NUMERIC` | Arbitrary precision |

- **Precision (p)**: Total significant digits
- **Scale (s)**: Digits after decimal point

### Examples

```sql
-- Price with 2 decimal places, up to 999999.99
price DECIMAL(8, 2)

-- Latitude/longitude with high precision
latitude NUMERIC(10, 7)

-- Exact financial calculations
balance NUMERIC(15, 2)
```

### Usage

```sql
CREATE TABLE products (
    id SERIAL PRIMARY KEY,
    price DECIMAL(10, 2) NOT NULL,
    tax_rate DECIMAL(5, 4) DEFAULT 0.0825
);

INSERT INTO products (price, tax_rate) VALUES (29.99, 0.0825);

-- Calculations preserve precision
SELECT price * (1 + tax_rate) AS total FROM products;
-- Result: 32.4641825 (not rounded)
```

## Floating-Point Types

Approximate numeric for scientific calculations:

| Type | Storage | Precision |
|------|---------|-----------|
| `REAL` / `FLOAT4` | 4 bytes | ~6 decimal digits |
| `DOUBLE PRECISION` / `FLOAT8` | 8 bytes | ~15 decimal digits |
| `FLOAT(p)` | Variable | At least p digits |

### Usage

```sql
CREATE TABLE measurements (
    sensor_id INTEGER,
    temperature REAL,
    pressure DOUBLE PRECISION
);

-- Float with specified precision
CREATE TABLE scientific (
    measurement FLOAT(24)  -- At least 24 bits of precision
);
```

### Caution

Floating-point has rounding errors:

```sql
SELECT 0.1::REAL + 0.2::REAL;
-- May not equal exactly 0.3

-- Use DECIMAL for money!
SELECT 0.1::DECIMAL + 0.2::DECIMAL;
-- Exactly 0.3
```

---

## Special Values

Floating-point types support:

| Value | Description |
|-------|-------------|
| `'Infinity'` | Positive infinity |
| `'-Infinity'` | Negative infinity |
| `'NaN'` | Not a number |

```sql
SELECT 'Infinity'::DOUBLE PRECISION;
SELECT 1.0 / 0;  -- Error in strict mode

-- Check for infinity
SELECT value, value = 'Infinity' AS is_infinite FROM measurements;
```

## Type Casting

```sql
-- String to number
SELECT '123'::INTEGER;
SELECT CAST('123.45' AS DECIMAL(10,2));

-- Between numeric types
SELECT 123::BIGINT;
SELECT 123.456::INTEGER;  -- Truncates to 123

-- Rounding
SELECT ROUND(123.456::NUMERIC, 2);  -- 123.46
```

## Arithmetic

| Operator | Description | Example |
|----------|-------------|---------|
| `+` | Addition | `5 + 3` → `8` |
| `-` | Subtraction | `5 - 3` → `2` |
| `*` | Multiplication | `5 * 3` → `15` |
| `/` | Division | `5 / 3` → `1` (integer) |
| `%` | Modulo | `5 % 3` → `2` |
| `^` | Power | `2 ^ 3` → `8` |

### Division Note

Integer division truncates:

```sql
SELECT 5 / 3;          -- 1 (integer)
SELECT 5.0 / 3;        -- 1.666... (decimal)
SELECT 5 / 3.0;        -- 1.666... (decimal)
SELECT 5::DECIMAL / 3; -- 1.666... (decimal)
```

## Comparison

```sql
-- Standard comparisons
WHERE price > 100
WHERE quantity <= 0
WHERE rating BETWEEN 3.5 AND 5.0

-- NULL handling
WHERE quantity IS NULL
WHERE COALESCE(quantity, 0) = 0
```

## Choosing the Right Type

| Use Case | Recommended Type |
|----------|------------------|
| IDs, counts | `INTEGER` or `BIGINT` |
| Money, financial | `DECIMAL(p,s)` |
| Scientific | `DOUBLE PRECISION` |
| Auto-increment | `SERIAL` or `BIGSERIAL` |
| Percentages | `DECIMAL(5,2)` or `DECIMAL(5,4)` |
| Coordinates | `DECIMAL(10,7)` |
