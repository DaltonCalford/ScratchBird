# Type Mapping Guide

## Universal Type System

ScratchBird uses a universal type system that maps to all supported databases.

## Numeric Types

### Integer Types

| ScratchBird | PostgreSQL | MySQL | MSSQL | Firebird | Range |
|-------------|------------|-------|-------|----------|-------|
| INT8 | - | TINYINT | tinyint | - | -128 to 127 |
| UINT8 | - | TINYINT UNSIGNED | - | - | 0 to 255 |
| INT16 | smallint | SMALLINT | smallint | SMALLINT | -32,768 to 32,767 |
| INT32 | integer | INT | int | INTEGER | -2^31 to 2^31-1 |
| INT64 | bigint | BIGINT | bigint | BIGINT | -2^63 to 2^63-1 |

### Conversion Rules
```cpp
// Automatic widening conversions (safe)
INT8 -> INT16 -> INT32 -> INT64

// Narrowing conversions (require check)
INT64 -> INT32: if (value > INT32_MAX || value < INT32_MIN) throw overflow_error;
```

### Auto-Increment Mapping

| Database | Declaration | ScratchBird Internal |
|----------|-------------|---------------------|
| PostgreSQL | SERIAL | INT32 + SEQUENCE |
| PostgreSQL | BIGSERIAL | INT64 + SEQUENCE |
| MySQL | AUTO_INCREMENT | INT32/64 + AUTO_SEQ |
| MSSQL | IDENTITY(1,1) | INT32/64 + IDENTITY_SEQ |
| Firebird | GENERATED BY DEFAULT AS IDENTITY | INT32/64 + GENERATOR |

```cpp
class AutoSequence {
    UUID column_id;
    int64_t current_value;
    int64_t increment;
    
    int64_t next_value() {
        return atomic_fetch_add(&current_value, increment);
    }
};
```

## String Types

### Character Types

| ScratchBird | PostgreSQL | MySQL | MSSQL | Firebird | Notes |
|-------------|------------|-------|-------|----------|-------|
| CHAR(n) | char(n) | CHAR(n) | char(n) | CHAR(n) | Fixed, padded |
| VARCHAR(n) | varchar(n) | VARCHAR(n) | varchar(n) | VARCHAR(n) | Variable |
| TEXT | text | TEXT | varchar(max) | BLOB SUB_TYPE TEXT | Unlimited* |

*Actual limits:
- PostgreSQL: 1GB
- MySQL: 65,535 bytes (TEXT), 4GB (LONGTEXT)
- MSSQL: 2GB (varchar(max))
- Firebird: 32KB (VARCHAR), larger needs BLOB

### String Storage Strategy
```cpp
class StringStorage {
    enum Storage {
        INLINE,      // <= 255 bytes: store in tuple
        EXTENDED,    // <= 8KB: store in same page
        EXTERNAL     // > 8KB: store in BLOB/TOAST
    };
    
    Storage decide(size_t length) {
        if (length <= 255) return INLINE;
        if (length <= 8192) return EXTENDED;
        return EXTERNAL;
    }
};
```

## Special Types

### Boolean

| Database | Type | True Values | False Values | NULL |
|----------|------|-------------|--------------|------|
| PostgreSQL | boolean | TRUE, 't', 'true', 'y', 'yes', '1' | FALSE, 'f', 'false', 'n', 'no', '0' | NULL |
| MySQL | BOOLEAN/TINYINT(1) | 1, TRUE | 0, FALSE | NULL |
| MSSQL | bit | 1 | 0 | NULL |
| Firebird | BOOLEAN | TRUE | FALSE | NULL |

```cpp
class BooleanValue {
    enum State { FALSE = 0, TRUE = 1, NULL_VALUE = 2 };
    State value;
    
    int to_mysql() { return value == TRUE ? 1 : 0; }
    string to_postgresql() { return value == TRUE ? "t" : "f"; }
    int to_mssql() { return value == TRUE ? 1 : 0; }
};
```

## Type Coercion Rules

### Implicit Conversions (Automatic)

```
Numeric widening:
INT8 → INT16 → INT32 → INT64 → DECIMAL → FLOAT32 → FLOAT64

String widening:
CHAR(n) → VARCHAR(n) → TEXT

Temporal widening:
DATE → TIMESTAMP
TIME → TIMESTAMP
```

### Explicit Conversions (CAST Required)

```sql
-- String to numeric
CAST('123' AS INTEGER)

-- Numeric to string
CAST(123 AS VARCHAR(10))

-- Timestamp to date (loses time)
CAST(TIMESTAMP '2024-01-01 12:34:56' AS DATE)
```

## Client-Specific Type Presentation

```cpp
class TypePresenter {
    string present_type(DataType type, ClientType client) {
        switch (client) {
            case POSTGRESQL:
                return postgresql_type_name(type);
            case MYSQL:
                return mysql_type_name(type);
            case MSSQL:
                return mssql_type_name(type);
            case FIREBIRD:
                return firebird_type_name(type);
        }
    }
    
    Value present_value(Value val, ClientType client) {
        // Format value according to client expectations
        if (client == MYSQL && val.type == BOOLEAN) {
            return Value(val.as_bool() ? 1 : 0);  // MySQL uses TINYINT
        }
        // ... other conversions
    }
};
```
