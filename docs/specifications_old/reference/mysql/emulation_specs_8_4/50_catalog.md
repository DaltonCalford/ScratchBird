MySQL 8.4 internal catalog (data dictionary tables)

Source of truth
- MySQL DD table definitions: sql/dd/impl/tables/*.cc

Notes
- The persistent data dictionary is stored in the mysql schema (dd tables).
- information_schema is implemented as views/virtual tables backed by DD; performance_schema and sys are separate subsystems.
