# SBLR V3 Old-to-New Opcode Mapping (Master)

Status: Authoritative (V3)
Last Updated: 2026-02-08

This table maps legacy SBLR opcodes (V2, including extended opcodes) to the new V3 opcode IDs.
The mapping is grouped by semantic category. New opcode names are normalized by removing the `EXT_` prefix
and adding the `SBLR3_` prefix. All values are 16-bit and encoded as little-endian unsigned integers.
