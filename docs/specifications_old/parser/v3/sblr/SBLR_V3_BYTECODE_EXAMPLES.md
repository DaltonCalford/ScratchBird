# SBLR V3 Bytecode Examples (DDL/DML Variants)
Status: Authoritative (V3)
Last Updated: 2026-02-08

Purpose: provide deterministic, byte-level payload examples for every common
DDL/DML variant so a low-context AI can emit bytecode without ambiguity.

Encoding rules: little-endian, `string = [len:varuint][utf8]`, `schema_path = [count][ident...]`,
`list<T> = [count][T...]`, `opt<T> = [present:bool][T if present]`.

Unless stated otherwise, the bytes shown are **payload-only** (the instruction
header `[opcode:u16][flags:u16][payload_len:u32]` is omitted).

Nested expressions are encoded as full nested instructions (header + payload)
inside the parent payload.
