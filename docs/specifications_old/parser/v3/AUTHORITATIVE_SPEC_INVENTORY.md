## Update Procedure (Authoritative)

1. Any change to an authoritative file **MUST** update this inventory.
2. Inventory entries must be regenerated in **lexicographic path order**.
3. Hash algorithm is **SHA256** over raw file bytes.
4. The `Generated:` line must be updated with the local date.

## Validation Rules (Authoritative)

- Every path listed **MUST exist** and be readable.
- No authoritative file may be omitted.
- No non‑authoritative file may appear here.
- Duplicate paths are forbidden.

## CI Gate (Required)

CI MUST verify:
- All authoritative files are present in the inventory.
- Hashes match the current file contents.
- The inventory file itself is included and hashed.
