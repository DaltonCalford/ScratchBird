# Evidence Expectations

## General Rule

A ticket is complete only when the package trackers, canonical specs, audit
matrix, and evidence artifacts all agree.

## Ticket Expectations

- B1-02-001: updated canonical specs with missing details removed
- B1-02-002: current search-key audit matrix and ownership map
- B1-02-003: lane A implementation and spec evidence
- B1-02-004: lane B implementation and spec evidence
- B1-02-005: lane-specific gate and benchmark evidence
- B1-02-006: final tracker completion and move-ready closeout note
