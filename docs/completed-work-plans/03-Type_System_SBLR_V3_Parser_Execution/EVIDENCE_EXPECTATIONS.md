# Evidence Expectations

## General Rule

A ticket is complete only when the package trackers, canonical specs, audit
matrix, and evidence artifacts all agree.

## Ticket Expectations

- B1-03-001: updated canonical specs with missing details removed
- B1-03-002: current search-key audit matrix and ownership map
- B1-03-003: lane A implementation and spec evidence
- B1-03-004: lane B implementation and spec evidence
- B1-03-005: lane-specific gate and benchmark evidence
- B1-03-006: final tracker completion and move-ready closeout note
