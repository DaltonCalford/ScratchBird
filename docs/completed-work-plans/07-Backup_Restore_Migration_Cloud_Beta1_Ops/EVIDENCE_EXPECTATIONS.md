# Evidence Expectations

## General Rule

A ticket is complete only when the package trackers, canonical specs, audit
matrix, and evidence artifacts all agree.

## Ticket Expectations

- B1-07-001: updated canonical specs with missing details removed
- B1-07-002: current search-key audit matrix and ownership map
- B1-07-003: lane A implementation and spec evidence
- B1-07-004: lane B implementation and spec evidence
- B1-07-005: lane-specific gate and benchmark evidence
- B1-07-006: final tracker completion and move-ready closeout note
