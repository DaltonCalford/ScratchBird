# Change Request (CR)

- CR ID: CR-002
- Title: Clarify file locking requirements for Alpha
- Phase: ALPHA-1.01
- Author: AI B
- Date: 2024-12-31

## Summary
- Problem/ambiguity: AUTHORITATIVE_IMPLEMENTATION_PLAN.md states "File lock prevents concurrent access" but implementation and tests show this is not fully enforced
- Proposed change: Clarify that Alpha uses advisory locking with `flock()` and document that mandatory locking will be implemented in Beta
- Impacted files/specs: AUTHORITATIVE_IMPLEMENTATION_PLAN.md, test_lock_conflict.cpp

## Rationale
- Current implementation uses `flock(fd, LOCK_EX | LOCK_NB)` which is advisory locking
- test_lock_conflict.cpp explicitly tests and expects that double-open succeeds at OS level
- Comment in test states "in future we will enforce lock files"
- This creates confusion about what level of protection is expected in Alpha

## Acceptance
- Updated specs/plan references: AUTHORITATIVE_IMPLEMENTATION_PLAN.md clarifies advisory vs mandatory locking
- Tests added/updated: Current test correctly reflects Alpha behavior
