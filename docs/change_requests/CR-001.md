# Change Request (CR)

- CR ID: CR-001
- Title: Add OOM error code to Status enum
- Phase: ALPHA-1.01
- Author: AI B
- Date: 2024-12-31

## Summary
- Problem/ambiguity: MEMORY_MANAGEMENT.md requires SB_ERR_OOM error code but Status enum in status.h is missing this value
- Proposed change: Add `OOM = 3003` to the Status enum to match ERROR_HANDLING.md specification
- Impacted files/specs: include/scratchbird/core/status.h, all memory allocation sites

## Rationale
- The MEMORY_MANAGEMENT.md specification explicitly states: "All allocators must check for NULL from malloc/calloc/realloc/new and return SB_ERR_OOM"
- The ERROR_HANDLING.md defines SB_ERR_OOM = 3003 in the error code list
- Current Status enum is missing this critical error code, making it impossible to properly report allocation failures
- This creates undefined behavior when memory allocation fails

## Acceptance
- Updated specs/plan references: Status enum matches ERROR_HANDLING.md
- Tests added/updated: OOM simulation tests once error code is available
