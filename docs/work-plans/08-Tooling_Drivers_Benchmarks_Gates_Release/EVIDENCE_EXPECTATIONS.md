# Evidence Expectations

## General Rule

A ticket is complete only when the package trackers, canonical specs, audit
matrix, and evidence artifacts all agree.

## Ticket Expectations

- B1-08-001: updated canonical specs with missing details removed
- B1-08-002: current search-key audit matrix and ownership map
- B1-08-003: lane A implementation and spec evidence
- B1-08-004: lane B implementation and spec evidence, throughput diagnosis, and performance remediation plan with focused before/after probes
- B1-08-005: lane-specific gate and benchmark rerun evidence after the active performance blocker is remediated
- B1-08-006: final tracker completion and move-ready closeout note
