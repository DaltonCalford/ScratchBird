# NoSQL and Multi-Model (Beta Requirements)

**[Back to Beta Requirements](../README.md)**

This directory contains the Beta planning documents for NoSQL data models and
multi-model support. The focus is on storage structures and core engine
requirements (not query language syntax).

## Documents

- [NOSQL_STORAGE_STRUCTURES_REPORT.md](NOSQL_STORAGE_STRUCTURES_REPORT.md) -
  Gap analysis of NoSQL storage structures and the ScratchBird coverage plan.
- [NOSQL_CATALOG_MODEL_SPEC.md](NOSQL_CATALOG_MODEL_SPEC.md) - Catalog objects
  for collections, buckets, column families, and graphs.
- [JSONPathIndex.md](../../indexes/JSONPathIndex.md) - JSON path index design
  and catalog wiring (index specs are centralized under `indexes/`).
