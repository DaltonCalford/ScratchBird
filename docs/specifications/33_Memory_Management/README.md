# Section 33 Memory Management

Status: current_authority

This section owns the canonical ScratchBird memory model: allocator boundaries,
buffered and runtime memory behavior, spill and temporary memory seams,
pressure and admission rules, and memory observability.

Unsupported or narrower-than-commercial behaviors must be expressed only as
explicit fail-closed or non-guarantee boundaries inside the section files. This
section entry point is not a placeholder and is not a planning-only surface.

## Section scope

- memory ownership and allocator boundaries
- memory budget tree, breakers, and schema-root quotas
- typed allocators, arenas, and lifetime contexts
- buffered runtime memory model
- temporary memory and spill boundary
- operator reservation and memory grant feedback
- JIT metadata and code-memory ownership
- memory debt classes and scheduler binding
- memory pressure, backpressure, and admission
- memory observability and debugging boundary

## Audit lookup anchors

Representative section-33 audit anchors are:
- `replacement_ghost_history_pct`
- `speculative_prefetch`
- `reserveBytes(`
- `TempPageState::SPILLED`
