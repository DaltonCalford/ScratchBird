# Cluster UDR Fabric Channel Specification

## Current status

Parserless cluster or UDR fabric transport is not part of the shipped current
section `26` native or IPC transport contract.

## Required interpretation

- No current implementation may claim this document as active wire authority.
- No `0x08xx` cluster-fabric runtime is certified by current section `26`.
- Any future promotion requires direct runtime code, tests, and cross-section
  ownership alignment with the sections that own cluster and function fabrics.
