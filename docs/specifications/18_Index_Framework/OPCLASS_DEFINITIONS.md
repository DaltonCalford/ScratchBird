# Opclass Definitions (Alpha)

## Purpose
Define fully specified opclasses required for GiST, SP-GiST, and GIN in Alpha. Any opclass not listed here MUST be rejected by all parsers in Alpha.

## GiST Opclasses

### `gist_rtree_2d`
Applies to 2D geometry and spatial predicates.

#### Key Type
- Minimum Bounding Rectangle (MBR):
  - `xmin` (f64), `ymin` (f64), `xmax` (f64), `ymax` (f64)

#### Functions
1. `compress(value)`:
   - If value is a point `(x,y)`, return `xmin=xmax=x`, `ymin=ymax=y`.
   - If value is a line/polygon, return the axis-aligned bounding box of all vertices.
2. `union(keys[])`:
   - Return MBR that spans all input MBRs:
   - `xmin=min(xmin_i)`, `ymin=min(ymin_i)`, `xmax=max(xmax_i)`, `ymax=max(ymax_i)`.
3. `penalty(existing_key, new_key)`:
   - Compute area enlargement:
   - `area(mbr) = max(0, xmax-xmin) * max(0, ymax-ymin)`.
   - `penalty = area(union(existing_key, new_key)) - area(existing_key)`.
4. `picksplit(keys[])`:
   - Use quadratic split:
   - Seed selection: choose the pair with maximum wasted area if grouped.
   - Distribute remaining keys by minimal penalty; tie-breaker is smaller area.
   - Enforce min fill `m = floor(0.4 * M)`.
5. `consistent(query, key)`:
   - For query bounding box `Q`, return true if `key` intersects `Q`.
   - `intersects` if rectangles overlap in both X and Y.
   - Set `recheck=true` for all results (exact geometry check required).
6. `same(key1, key2)`:
   - Return true if all four coordinates are equal.

## SP-GiST Opclasses

### `spgist_point_quad`
Applies to 2D points with quad-tree partitioning.

#### Functions
1. `config()`:
   - Prefix type: none.
   - Node label type: quadrant id (u8: 0=SW,1=SE,2=NW,3=NE).
2. `choose(point, inner_tuple)`:
   - Compute quadrant from inner tuple centroid `(cx,cy)`:
     - SW: x < cx and y < cy
     - SE: x >= cx and y < cy
     - NW: x < cx and y >= cy
     - NE: x >= cx and y >= cy
3. `picksplit(points[])`:
   - Compute centroid `(cx, cy)` as median of x and y.
   - Partition points into 4 quadrants by centroid.
   - Build inner tuple storing centroid and quadrant labels.
4. `inner_consistent(query_rect, inner_tuple)`:
   - Return the set of quadrants whose rectangle intersects `query_rect`.
5. `leaf_consistent(query_rect, point)`:
   - Return true if point is inside `query_rect`.

### `spgist_text_prefix`
Applies to text prefix queries using radix partitioning.

#### Functions
1. `config()`:
   - Prefix type: UTF-8 byte string.
   - Node label type: single byte (u8).
2. `choose(text, inner_tuple)`:
   - Compare the next byte of `text` after the inner prefix.
   - Route to child with matching byte; if none, create a new child.
3. `picksplit(texts[])`:
   - Find the longest common prefix of all texts.
   - Create an inner tuple with that prefix.
   - Partition by the next byte after the prefix.
4. `inner_consistent(prefix_query, inner_tuple)`:
   - If `prefix_query` does not match inner prefix, return no children.
   - Else return all children whose label matches the next byte of `prefix_query`, or all children if `prefix_query` is fully consumed.
5. `leaf_consistent(prefix_query, text)`:
   - Return true if `text` starts with `prefix_query`.

## GIN Opclasses

### `gin_array`
Applies to arrays of scalar types (int, float, string, uuid).

#### Functions
1. `extract_value(array)`:
   - Return the set of unique elements.
   - Encode each element using `INDEX_KEY_ENCODING.md`.
2. `extract_query(array_query, strategy)`:
   - For strategy `overlap`: return all elements in the query array.
   - For strategy `contains`: return all elements in the query array.
   - For strategy `contained`: return all elements in the query array.
   - For strategy `equal`: return all elements in the query array.
3. `consistent(query_keys, index_keys, strategy)`:
   - `overlap`: true if any query key is present in index_keys.
   - `contains`: true if all query keys are present in index_keys.
   - `contained`: true if index_keys is subset of query_keys.
   - `equal`: true if both sets are identical.
   - `recheck=true` for all strategies (exact array comparison at heap).

### `gin_tsvector`
Applies to fulltext tokens as generated by FULLTEXT rules.

#### Functions
1. `extract_value(text)`:
   - Tokenize text using FULLTEXT rules for the active dialect.
   - Return unique tokens, encoded as UTF-8 bytes.
2. `extract_query(tsquery)`:
   - Parse boolean expression into terms with operators AND/OR/NOT/PHRASE.
   - Return the list of positive terms.
3. `consistent(query_terms, index_terms, tsquery)`:
   - Evaluate the tsquery expression using the presence of terms in index_terms.
   - For PHRASE, set `recheck=true` and allow candidate if all terms present.
   - For NOT, enforce exclusion at index level when possible, else set `recheck=true`.
