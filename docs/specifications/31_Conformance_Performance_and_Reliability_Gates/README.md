# Section 31 - Conformance, Performance, and Reliability Gates

Status: current_authority

## Scope

Section 31 defines the current ScratchBird gate framework, evidence artifacts, maintained certification lanes, benchmark and reliability method, and explicit non-claims for unsupported or non-maintained gate families.

## Current authority

Section 31 is authoritative for:
- what gate families currently exist
- what evidence artifacts are required for those gate families
- what maintained benchmark and conformance lanes are release-significant
- what platform and filesystem assumptions are currently certified
- what gate families remain unsupported, non-maintained, or fail-closed

Section 31 is not a speculative roadmap. Unsupported or unexecuted gate families are boundary statements, not implementation promises.

## Governing invariants inherited here

- Gate evidence must reflect the current MGA engine model.
- Gate evidence must not assume WAL-authoritative recovery or WAL replay.
- DDL and DML certification must use the same always-in-transaction model as the engine.
- Platform, tooling, and compatibility claims are valid only where section 31 defines maintained evidence requirements.
