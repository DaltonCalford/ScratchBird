# SBLR Feature-to-Opcode Matrix (Alpha)

## Purpose
Provide the authoritative mapping from section-21 `feature_key` entries to canonical SBLR statement opcode symbols and payload schema ids.

## Mapping Rules
1. Statement opcode symbol: `feature_key` with `F_` removed and `OP_STMT_` prepended.
2. Payload schema id: `feature_key` with `F_` removed and `PS_` prepended.
3. AST family is derived by deterministic prefix rules from `SBLR_OPCODE_FAMILIES_AND_SYMBOLS.md`.
4. `result_shape_id` must exactly match section-21 matrix.
