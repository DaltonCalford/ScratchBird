Status: current_authority

This section owns the canonical ScratchBird external data movement model:
backup and restore boundaries, bulk import and export surfaces, snapshot and
retention rules, portability limits, and explicit non-guarantees.

Where current runtime support is narrower than a full enterprise backup or DR
platform, that narrower scope must be expressed as explicit fail-closed or
non-guarantee language inside the section files. This section entry point is
not placeholder scaffolding.

## Section scope

- backup and restore boundary
- bulk import, export, and copy surfaces
- snapshot chain and retention model
- externalization and portability boundary
- non-guarantee and partial bulk-data behavior
