# Section 25 - Runtime Modes

Status: current_authority

## Current authority

Section `25` is the canonical current-state authority for:
- local worker and task runtime behavior
- workload governance, routing-admission metadata, SLO, and error-budget metadata surfaces
- local scheduler-backed maintenance control
- bounded parallel execution and planner-parallelism interaction shared with section `23`
- bounded cluster-write-safety primitives such as routing epoch, fencing token, and session pin
- bounded time and skew checks currently enforced in listener or control-plane paths
- derivative `WAL_AFTER_*` debug and export scope where current sweep/evidence paths expose it

## Unsupported-boundary files

The following families are not current implementation authority and must be treated as explicit unsupported-boundary or future-only documents:
- leader election, membership, metadata consensus, and log replication
- full cluster OLTP lifecycle, segmentation healing, and cluster-wide scheduler parity
- full cluster clock discipline
- full OLAP-node and specialized-node runtime parity
- universal layered runtime-stack, cluster read consistency, and cost-aware placement closure
- full cluster UDR fabric runtime parity, which is owned more deeply by section `17`

## Governing invariants

- ScratchBird is always in a transaction.
- Runtime mode does not change MGA transaction or durability semantics.
- The core engine is not the SQL parser and does not expose a direct generic network SQL surface.
- Listener, parser, IPC, and engine control planes remain split across sections `26` through `29`.
- WAL is not the recovery mechanism; any `WAL_AFTER_*` surface is derivative only.
