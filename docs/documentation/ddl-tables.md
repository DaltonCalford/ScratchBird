### DDL: Tables

CREATE/ALTER/DROP/RECREATE TABLE parsing is implemented in `src/engine/parser_ddl.cpp`.

Captured attributes in AST (`include/scratchbird/engine/ast.h`):
- `name`, `columns_raw`, `constraints_raw`, `column_defs_raw`, `table_attrs_raw`
- `alter_ops[]` with kind/target/raw for ALTER TABLE
- Column-level: computed_by, CHARACTER SET/COLLATE, NOT NULL, identity (ALWAYS/BY DEFAULT) with options
- Table constraints: PRIMARY KEY, UNIQUE, CHECK (expr), FOREIGN KEY with referenced columns and actions; DEFERRABLE/INITIALLY DEFERRED
- EXTERNAL FILE path if present

Syntax notes:
- Column/constraint list is split at top-level commas; parentheses depth tracking handles nested constructs
- ALTER TABLE operations are split and classified; diagnostics for missing TYPE targets

Examples:
```sql
CREATE TABLE t (
  id INTEGER GENERATED BY DEFAULT AS IDENTITY,
  name VARCHAR(100) CHARACTER SET UTF8 COLLATE unicode,
  CONSTRAINT pk PRIMARY KEY (id),
  CONSTRAINT u UNIQUE (name),
  CHECK (name IS NOT NULL)
);

ALTER TABLE t ADD COLUMN created_at TIMESTAMP;
ALTER TABLE t ALTER COLUMN name TYPE VARCHAR(200);
```

Code anchors: `src/engine/parser_ddl.cpp` (parse_ddl_table)
