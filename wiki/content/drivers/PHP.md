**Status:** Alpha documentation (in progress)

## Recommended Path

- Use ScratchBird native protocol when a native driver is available (port 3092).
- For dialect compatibility, use existing ecosystem drivers against the
  PostgreSQL/MySQL/Firebird listeners.

## Connection Notes

- Native port: 3092
- PostgreSQL port: 5432
- MySQL port: 3306
- Firebird port: 3050
