# Driver Comparison

**Status:** Alpha documentation (in progress)
**Last Updated:** 2026-01-09

ScratchBird supports multiple access paths:
- Native protocol (port 3092)
- PostgreSQL (port 5432)
- MySQL (port 3306)
- Firebird (port 3050)

Driver status varies by language and phase. See:
- `docs/specifications/beta_requirements/drivers/`
- `docs/user-documentation/connectivity/`
