# Common Errors

**Status:** Alpha documentation (in progress)
**Last Updated:** 2026-01-09

## Connection Refused
- Verify server is running and ports are open.
- Confirm protocol port (3092/5432/3306/3050).

## Authentication Failed
- Verify user credentials and auth method.
- Confirm the dialect parser/adapter matches the client protocol.
