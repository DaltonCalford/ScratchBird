# Common Errors

**Last Updated:** 2026-02-03

---

## Connection Errors

- **Authentication failed**: Verify user/password and HBA rules.
- **Connection refused**: Confirm listener enabled and port open.
- **Timeouts**: Check firewall, host, and server load.

## SQL Errors

- **Syntax error**: Confirm dialect and quoting rules.
- **Permission denied**: Verify GRANT/REVOKE for the object.
- **Object not found**: Check schema search path and qualified names.

## Storage Errors

- **Out of space**: Verify data directory capacity and cleanup.
- **I/O errors**: Check disk health and OS logs.
