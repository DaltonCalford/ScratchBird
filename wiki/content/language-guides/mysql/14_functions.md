# Functions

**Last Updated:** 2026-02-03

---

Common MySQL function groups:

- Aggregates: COUNT, SUM, AVG, MIN, MAX
- Date/Time: NOW, CURRENT_DATE, CURRENT_TIMESTAMP
- String: LENGTH, SUBSTRING, LOWER, UPPER, CONCAT
- JSON: JSON_EXTRACT, JSON_OBJECT, JSON_ARRAY

## Differences

- Plugin/UDF functions are available only if explicitly registered.
