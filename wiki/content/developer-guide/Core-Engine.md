# Core Engine

**Last Updated:** 2026-02-03

---

The core engine executes SBLR bytecode, manages MGA transactions, and
coordinates storage/index subsystems.

Key subsystems:
- SBLR executor
- Transaction manager (TIP/MGA)
- Catalog manager
- Buffer pool and page manager
- Index subsystem
