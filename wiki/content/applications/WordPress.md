# WordPress

**Last Updated:** 2026-02-03

---

ScratchBird can be used as a backend for WordPress when the MySQL protocol
listener and compatible driver are available.

## Steps

1. Enable the MySQL listener in `sb_server.conf`.
2. Create a database and user for WordPress.
3. Configure WordPress `wp-config.php` to point at ScratchBird.
4. Run WordPress installation and verify read/write paths.
