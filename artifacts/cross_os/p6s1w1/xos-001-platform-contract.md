# XOS-001 Platform Contract
Last-Modified: 2026-02-22

## Scope Freeze
This contract freezes the target matrix for cross-OS enablement in phase `P6`.

## Target Matrix
| Target ID | OS | Arch | Compiler | Build Mode | Status |
| --- | --- | --- | --- | --- | --- |
| `linux-gcc-x64` | Linux | x86_64 | GCC | native | required |
| `linux-clang-x64` | Linux | x86_64 | Clang | native | required |
| `windows-msvc-x64` | Windows | x86_64 | MSVC (VS 2022 toolchain) | native | required |
| `windows-mingw-x64` | Windows | x86_64 | MinGW-w64 | cross from Linux | required |

## Toolchain Baselines
1. CMake minimum: `3.20` (from project root `CMakeLists.txt`).
2. C++ language baseline: `C++17`.
3. Linux CI baseline: Ubuntu latest with `g++` and optional `clang++`.
4. Windows native baseline: Visual Studio 2022 (`cl` toolchain).
5. Windows cross baseline: `x86_64-w64-mingw32` toolchain on Linux.

## Build Profiles
1. `debug`: sanitizer and diagnostics profile (Linux required).
2. `relwithdebinfo`: default CI verification profile.
3. `release`: packaging profile for runtime artifacts.

## Compatibility Rules
1. Linux behavior remains normative baseline.
2. Windows implementation must preserve parser/emitter/executor semantics.
3. Any Linux-only behavior must be explicitly feature-gated and documented.
4. Release artifacts are generated by jobs and must not be committed to git.
